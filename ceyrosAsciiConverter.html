How everything works

    

      Veni, vidi, converti — I came, I saw, I converted. Offline tools for ASCII plates, banners, and utilities.
    


    

      
01 Image → ASCII

      

        Drop or choose an image. Ordered dither (clean) makes chunky bone-on-black plates.
        Detail level = columns (lower = bigger pixels). Download as PNG or HTML.
      

    


    

      
02 Text to ASCII

      

        Type text, pick a style (Block, Big, Slant, Bubble, Wave, Glitch, Typewriter…), color and size, Convert.
        Copy ASCII puts the banner on the clipboard. Download MP4 records a short animation
        (WebM/MP4 depending on browser).
      

    


    

      
03 Text Editor

      

        Write or paste, set filename and extension, then Download File.
        Optional: check also download a humanized copy to get a second file with softer
        AI-style phrasing (-humanized suffix). The editor text stays unchanged.
      

    


    

      
04 Image Formats & Paint

      

        Convert images to PNG / JPG / WebP. Paint: brush, colors, eraser, PNG download.
      

    


    

      
05 Games

      

        Tetris — arrows, Space hard drop, P pause.

        Dino Runner — Chrome-style; higher jump for easier play. Space / Up / click / tap.
      

    


    

      
06 JAR Analyzer

      

        Offline scan: structure, risk heuristics, interesting strings. Recovered resource text and class
        constant-pool strings appear in expandable code panels in the page — no .sh decompile script.
      

    


    

      
07 MP3 Cover

      

        Choose MP3 + cover image. Optional Artist tag (TPE1). Embed & download writes ID3v2 art
        (and artist if set), then clears the form.
      

    


    

      
08 Other

      

        Phone Preview, System / IP, Cheat Sheets. EN / DE, [*] theme,
        [lo] low-power mode. Humanize is an optional download under Text Editor.
